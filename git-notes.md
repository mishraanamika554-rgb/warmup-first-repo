INTRODUCTION
Git is version control system used to track changes in files and collaborate with developers.
GitHub is an online  platform used to store and share git  repositories.

BASIC GIT COMMAND THAT I IPRACTICED
git clone <repo link>: copied the repo with all the files on system. 
git status: used to check the current status of the repo.
git add README.md: stages the readme files for commit.
git commit-m "Add warmup onboarding learnings" : commited changes with a message.
git add.: stages all changes in the current directory.
git pull: retrieved and integrated remote changes.
git branch: listed the local branches that are present in the repo.
